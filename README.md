# Ayman Alimlahi — Full-Stack Developer Portfolio

A modern, responsive personal website featuring an animated developer intro, subtle motion, real portfolio case studies, and mobile-friendly navigation.

## Preview

Open `index.html` in a browser. For the best local experience, serve this folder using any simple static web server, for example:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

No installation or build step is required. Google Fonts are optional: system fallbacks work offline.

## Customize

- Change copy, content, social links, and project cards in `index.html`.
- Change colors, spacing, and typography in `styles.css` (the `:root` variables are at the top).
- Change loading animation duration or case-study text in `script.js`.
- Replace the CV file in `assets/` when you update your resume.

### Before publishing

The CV describes professional internships and operational roles; it does not provide public demo or exact GitHub repository URLs for the two featured projects. The site intentionally links to the known GitHub *profile* and does **not** pretend to have verified live demos. Add real project screenshots, source-repository links, and deployed demos when available.

To publish for free, use GitHub Pages, Cloudflare Pages, or Netlify as a static site. Upload the entire folder; no server/database is required.
